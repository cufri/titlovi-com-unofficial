# Titlovi.com unofficial — Cloudflare v2.3.0

## Ново

Опција **оригинал + кирилична верзија** за три јазици: `srp`, `hrv`, `bos`.
Оригиналните преводи остануваат непроменети. Дополнителниот превод е означен `[CYR]` во `id` и `label`, а го задржува оригиналниот јазичен код. Англиски и македонски се непроменети.

Транслитерацијата не е преведување: хрватскиот/босанскиот текст останува ист по јазик, само на кирилица според српската стандардна транслитерациска мапа. Времињата се пренесуваат од SRT/VTT во WebVTT без промена на вредностите. Претворањето на `nj`, `lj`, `dž` е контекстно ограничено и може да погреши кај ретки зборови/имиња. Странски зборови напишани со латиница исто така ќе се транслитерираат.

## Инсталација

1. Отпакувај во **нова папка**; чувај ја претходната стабилна верзија.
2. Во новата папка:

```cmd
npm install
npm test
npm run deploy
```

3. Провери `https://titlovi-com-unofficial.cufri.workers.dev/health` — треба да пишува `2.3.0`.
4. Отвори `https://titlovi-com-unofficial.cufri.workers.dev/configure`, внеси ја **својата приватна** официјална Titlovi.com manifest адреса, избери јазици и активирај „Прикажи оригинални + кирилични верзии“ (стандардно вклучено) и сите `srp`, `hrv`, `bos`.
5. Креирај **нов приватен инсталациски линк**, инсталирај го како посебен додаток во Nuvio. Не го споделувај тој линк или `CONFIG_SECRET`.

**Не го менувај `CONFIG_SECRET`** — старите конфигурирани инсталациски линкови зависат од него. Ако `npm run deploy` не ја најде тајната, постави ја преку `npx wrangler secret put CONFIG_SECRET`, со истата постојна вредност.

## Технички детали

- Одговорот за титлови враќа оригиналните URL-адреси и дополнителни шифрирани `/convert/<token>.vtt` URL-адреси за избраните јазици.
- Worker го презема избраниот оригинален SRT/VTT дури кога плеерот ќе побара кирилична верзија.
- Приватната адреса на оригиналниот титл е заштитена со AES-GCM токен; не се става директно во конверзиониот URL.
- Режим на пренасочување `manual` (поправката од v2.1).
- Лимит 1 MiB за директна текстуална датотека; ZIP/RAR/7z архиви и HTML/login содржини намерно се одбиваат. За таков титл оригиналот останува достапен, но кириличниот линк може да не работи.
- Вклучено optional R2 складирање на излезен VTT и на листи со титлови; ако нема R2 binding, работи без кеш. За да овозможиш R2, креирај bucket и откоментирај го binding-от во `wrangler.toml`. Провери ја тековната цена/квота пред да овозможиш.
- UTF-8 е главно поддржано кодирање; за текст што не е валиден UTF-8 се применува Windows-1250 како резервен декодер. Некои стари Windows-1251 титлови може да бараат дополнителна детекција.
- Во новата верзија стариот избор `detectScript` е сочуван, но за „both“ **не мора** да се вклучи. Препорачано: исклучи го, бидејќи веќе не зависиме од детекција на писмото.
- Екстерните преводи и серверот Titlovi.com се надвор од контрола на додатокот. Самата оригинална и кирилична верзија треба да се тестираат во Nuvio.
- **Cloudflare deployment не е направен од оваа архива** — потребна е горната `npm run deploy` команда од твојот терминал.

## Безбедност

Не ги ставај приватните `/c/...` или `/convert/...` линкови во јавни логови, форуми или GitHub. Извори на титлови се ограничени на HTTPS и се отфрлаат приватни/локални hostname форми; за целосно продукциско зацврстување се препорачува ограничување на конкретните доверливи титл-хостови.
